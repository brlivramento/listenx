# Web Player Music

A simple web-based music player with basic playback controls and support for importing MP3 files.

![Docker](https://img.shields.io/badge/Docker-2496ED?style=for-the-badge&logo=docker&logoColor=white)

## Prerequisites

Make sure Docker and Docker Compose are installed and the Docker engine is running.

## Run Locally

1. Clone the repository:

```bash
  git clone git@github.com:brlivramento/listenx.git
  cd listenx
```

2. Start the application:

```bash
docker compose up --build
```
